INVENTORY CASSANO — POSTGRES / GITHUB / RENDER

VERSI INI TIDAK MEMAKAI better-sqlite3.
Database memakai PostgreSQL dan foto barang disimpan sebagai data URL di database.
Karena itu aplikasi tidak membutuhkan persistent disk untuk database/foto.

DEPLOY DENGAN RENDER BLUEPRINT:
1. Upload seluruh isi folder ini ke GitHub repository inventory_cassano.
2. Di Render pilih New > Blueprint.
3. Pilih repository GitHub inventory_cassano.
4. Render membaca render.yaml dan membuat Web Service + PostgreSQL.
5. DATABASE_URL otomatis dihubungkan dari Postgres ke Web Service.
6. Deploy.

CATATAN RENDER FREE:
- Free Web Service tersedia untuk testing/hobby.
- Free Render Postgres saat ini hanya 1 GB dan expire 30 hari. Setelah 30 hari database harus di-upgrade jika ingin mempertahankan data.
- Untuk penggunaan permanen, upgrade Postgres sebelum masa 30 hari berakhir.
