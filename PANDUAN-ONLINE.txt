INVENTORY CASSANO — VERSI PRODUCTION

Tujuan:
Versi ini dibuat supaya kamu tidak perlu mengubah source code untuk menjalankannya.
Backend, database SQLite, login, role, permission, inventory, foto, keranjang, approval,
dan riwayat sudah ada.

PILIH CARA PALING MUDAH

A. VPS / SERVER DENGAN DOCKER
1. Upload seluruh folder ke server.
2. Install Docker + Docker Compose.
3. Jalankan:
   docker compose up -d --build
4. Website berjalan di port 3000.
5. Pasang reverse proxy/domain ke port 3000.
6. Volume cassano_data dan cassano_uploads membuat database dan foto tetap ada.

B. RENDER
1. Upload folder ini ke GitHub.
2. Di Render pilih New > Blueprint.
3. Pilih repository tersebut.
4. Render membaca render.yaml dan membuat service.
5. Setelah selesai, website mendapat URL *.onrender.com.
6. Untuk domain sendiri, tambahkan custom domain di pengaturan service.

CATATAN PENTING:
- Saya tidak bisa membuat domain publik atau melakukan deploy ke akun hosting milikmu tanpa akses akun/credential.
- Tidak perlu mengedit kode aplikasi.
- Untuk produksi yang lebih besar, gunakan PostgreSQL + object storage. Versi ini memakai SQLite + persistent disk agar setup paling sederhana.
- Jangan menghapus persistent disk karena di situlah database dan foto disimpan.

SETELAH LOGIN BOS

8. Tolak -> pesanan menjadi Rejected.
