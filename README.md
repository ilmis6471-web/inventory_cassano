# Inventory Cassano — PostgreSQL Edition

Versi online dengan PostgreSQL, cocok untuk GitHub → Render.

## Deploy
Upload semua file ke GitHub. Di Render gunakan **New → Blueprint** agar `render.yaml` membuat Web Service + Postgres dan menghubungkan `DATABASE_URL` otomatis.

**Catatan:** Free Render Postgres saat ini hanya untuk testing/hobby, 1 GB, dan expire 30 hari. Upgrade database sebelum expiry jika data ingin dipertahankan.
